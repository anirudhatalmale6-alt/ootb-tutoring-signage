# OOTB Tutoring — print files and logo

Everything you need to hand to a printer or a sign shop, in one folder.
Current as of 31 August 2026 (the business-card changes from feedback 34 are in).

## print-files/

Nine finished pieces. **Send the printer the PDF** — the PNG next to it is only
so you can look at it on screen.

- `OOTB-signage-proofs.pdf` — all nine on one PDF, for reviewing or emailing.
- `PRINT-SPECS.md` — bleed, trim, safe area and material notes for the printer.
- `WHATS-CHANGED.md` — what changed in the last round and why.
- `print-png/` — high-resolution PNGs, only if a supplier refuses PDFs.

Every PDF is exact trim size, pure vector, with the type converted to outlines,
so nothing shifts on a machine that does not have the fonts.

## logo/

- `svg/` — the masters. Give a designer or sign shop **these**, not the PNGs.
  `ootb-logo-primary.svg` is the everyday one; `ootb-logo-reversed.svg` is for
  dark backgrounds; the mono files are for one-colour printing and embroidery.
- `png/` — ready-to-use images with transparent backgrounds, 400 / 800 / 1600 px
  wide. Use the widest one that fits, never scale a small one up.
- `favicon/` — browser tab and phone home-screen icons for the website.
- `README.md` — which file to use when, the exact brand colours, and the
  minimum sizes below which the logo stops being legible.
